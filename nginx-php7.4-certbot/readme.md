# Nginx 1.24 + OpenSSL 3.5 + PHP 7.4 + Certbot

В этом варианте используется debian:trixie-slim (системный OpenSSL 3.5), Nginx 1.24.0 собирается с системными библиотеками, а PHP 7.4 и Certbot ставятся из пакетов.

Поскольку Nginx установлен из исходников в /etc/nginx, системный плагин python3-certbot-nginx может не найти его пути или конфликтует с ручной сборкой. Вместо него используется режим --webroot (он даже надежнее, так как Certbot не переписывает ваши конфиги сам)

В ветке Nginx 1.24 (как и во всех версиях до 1.30.7 / 1.31.9) обнаружены критические уязвимости в реализации HTTP/2 (CVE-2026-123633, CVE-2026-123007). Поскольку официальные патчи для 1.24 не выходят, при использовании этой версии не включайте директивы http2 on; или listen 443 ssl http2; в конфигурации, либо рассмотрите переход на актуальную стабильную ветку 1.30.7
